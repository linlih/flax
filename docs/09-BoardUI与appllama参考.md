# 09 参考 BoardUI 和 appllama-skills

> 2026-11-04。用户推荐了两个参考：BoardUI 网站和 appllama-skills（只用免费部分）。本文记录从中学到什么、怎么用到原型 v0.5。

## 1. 两个参考是什么

| 参考 | 是什么 | 用了哪部分 | 许可 |
|---|---|---|---|
| [BoardUI](https://www.boardui.com/zh-hans) | 一个 React + Tailwind 的仪表盘设计系统（103 个组件、400 多个设计变量），有免费版和 Pro | 只看了官网首页和免费的仪表盘模板页面，量取了颜色、圆角、阴影、字号；**没有复制代码或素材** | 视觉做法不受版权保护；如果以后直接用它的组件代码，需要先确认免费版的许可证 |

## 2. BoardUI 的视觉语言（实测值）

| 项目 | 值 |
|---|---|
| 结构 | 白色页面；每个区块是 `#F7F7F7` 托盘（圆角 16，内边距 8），里面放白色卡片（圆角 12，1px `#EBEBEB` 边框，`0 1px 2px rgba(0,0,0,.05)` 阴影） |
| 托盘标题 | 左上角一行灰色标签（14px / 500，`#737373`）+ 一个大数字（24px / 500，等宽数字），右上角放分段控件或按钮 |
| 颜色 | 中性灰全部无色相（Tailwind neutral：`#0A0A0A`、`#737373`、`#A1A1A1`）；唯一强调色是蓝，按钮和选中项用 `#2B7FFF → #155DFC` 竖向渐变，加一圈同色描边和顶部白色高光 |
| 控件 | 按钮高 36、圆角 10、白底描边；分段控件是灰底（圆角 10、内边距 4）里放白色选中项（圆角 6、高 28）；搜索框右侧有 `⌘K` 键盘提示 |
| 侧边栏 | 直接放在白底上，不加背景；行高 36、圆角 10；选中项是蓝色渐变底 + 白字，计数变成半透明白色小徽章 |
| 徽章和状态 | 徽章是浅色底 + 深色字（圆角 6）；表格里的状态是白色描边胶囊 + 小色点 + 文字 |
| 字体 | Inter + Noto Sans SC |

为什么好看：**一个结构反复用**（托盘 + 白卡），**一套圆角、一套阴影、一种强调色**，所以整页像一个整体，而不是拼起来的。

## 3. appllama-app-design-skill 里对我们有用的规则

它主要针对 Expo / React Native 手机应用，下面这些对桌面和 iPad 同样适用：

1. **先研究再画**：先看同类优秀应用的真实界面，提取"骨架"（布局、层次、主操作位置），不照抄像素。
2. **反模板清单**（每次提交前机械地数一遍）：强调色只有 1 种；圆角都来自一张固定的表；暖灰冷灰不混用；没有理由的渐变为 0；界面里的 emoji 为 0；同一意图只有一种说法。
3. **完整状态**：不只画成功状态。加载骨架和最终布局形状一致；空状态说明怎么填满；错误就地说明。
4. **数字像产品**：等宽数字、1.4M、38k 这样的格式。
5. **动效按频率决定**：每天上百次的操作（切换标签、滚动）用系统默认；按压反馈 100–150ms，按钮和卡片缩到 0.97–0.98，列表行只变底色；尊重"减少动态效果"。
6. **React Native 端**（以后做手机版时用）：原生控件优先、SF Symbols、`borderCurve: 'continuous'`、语义颜色、浅色和深色同时验证、在模拟器里录屏逐帧检查。

## 4. 原型 v0.5 的改法

- **文献库首页**：侧边栏改成 BoardUI 式（顶部工作区名、带 `⌘K` 的搜索框、蓝色渐变选中项、底部同步状态卡）；内容区改成三个托盘：
  - "继续阅读"：4 张白卡，每张是论文首页的上半部分 + 标题 + 作者 + 蓝色进度条；
  - "本周阅读"：阅读时长、增长徽章、7 天柱状图、两个小统计卡；
  - "最近加入"：表格（勾选、首页缩略图、来源、状态胶囊、批注数、加入时间），导入中和识别失败的文件直接作为表格行；勾选后标题变成批量操作。
- **阅读器**：缩略图栏、页面画布、检查器都放进托盘；笔记、卡片、AI 回答都放在白卡里；分段控件、按钮、来源标签换成同一套控件。
- **iPad**：结构不变，强调色统一为 `#155DFC`。
- **对比度修正**：BoardUI 的 `#737373` 放在 `#F7F7F7` 托盘上只有 4.4:1、`#A1A1A1` 只有 2.6:1，不够 WCAG AA（4.5:1）。我们把次要文字改成 `#6B6B6B`（托盘上 5.0:1），`#A1A1A1` 只留给占位符。
- 规则写进 [DESIGN.md](../DESIGN.md) v0.5。
