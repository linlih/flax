# 10 桌面 MVP 实施计划

> 2026-11-05。按 [06-路线图](06-路线图.md) 阶段 1 的范围，先做桌面端（Electron）。iPad 和手机等桌面 MVP 完成后再开始。
> 每个里程碑都要能运行、能演示、有测试，做完再进下一个。

## 技术栈（来自 [03-技术架构](03-技术架构.md)）

| 层 | 选择 |
|---|---|
| 仓库 | npm workspaces（`apps/*`、`packages/*`） |
| 桌面 | Electron + electron-vite + React + TypeScript |
| 共享逻辑 | `packages/core`：数据模型和纯函数，不依赖 Electron / Node / React Native |
| 设计 token | `packages/ui/tokens.css`：浅色和深色，来自 [DESIGN.md](../DESIGN.md) |
| 数据库 | SQLite：Electron 自带的 `node:sqlite`（带 FTS5 和中文可用的 trigram 分词），不用编译原生模块；测试和应用用同一个 SQLite |
| PDF | PDF.js（pdfjs-dist） |
| 测试 | Vitest（core 和主进程逻辑）；界面用 Playwright 驱动 Electron 做冒烟测试 |

## 进度

### M0（已完成）
仓库骨架、浅色和深色 token、桌面外壳（侧边栏 + 空文献库）。

### M1（已完成，待用真实论文验收）
- **存储**：数据在 `~/Library/Application Support/Paper/`（`library.sqlite` + `files/ab/<sha256>.pdf`）。不放"文稿"文件夹，因为它常开着 iCloud 同步，SQLite 放在那里容易损坏。测试时用环境变量 `PAPER_DATA_DIR` 换目录。
- **仓储层**：`packages/core/src/library.ts`。每条记录存 JSON，另抽 DOI、arXiv、规范化标题做索引；删除是软删除，可以撤销，以后同步时作为删除标记。
- **识别**：arXiv 页边戳 → 文件名里的编号 → 正文里的编号 / DOI；有 arXiv 编号先查 arXiv，否则查 Crossref；都没有就用 PDF 自带标题或首页最大字号的几行，标记"需要匹配"。arXiv 请求间隔 3 秒。
- **查重**：同一个文件（哈希相同）只提示；编号或长标题相同但文件不同，问"加为另一个版本 / 不导入"。
- **自动下载 PDF**：粘贴 arXiv 链接或编号后，先补元数据，再在后台从 `arxiv.org/pdf/<编号>` 下载 PDF（和 arXiv 查询共用 3 秒间隔，最大 200 MB）。失败时提示并可重试，详情页也有"从 arXiv 下载"。拖入的 PDF 如果对上库里还没有文件的论文，直接配上，不再问"另一个版本"。只有 DOI 的论文暂不自动下载（开放获取版本的查找放到以后）。
- **需要匹配**：按标题搜 Crossref 和 arXiv，按相似度排序让用户选；也可以手动填写。
- **还没做**：阅读器（现在"打开 PDF"用系统默认程序，M2 换掉）；文件名规则只用于显示，真正按规则导出放到 M6；验收需要用 10 篇真实论文跑一遍（我只用自己生成的 PDF 测过，其中两篇带真实编号，在线查询结果正确）。
- **应用名**：2026-11-06 定为 Flax，`app.setName` 和 Dock 图标已改。数据目录（`~/Library/Application Support/Paper`）、`paper://` 协议和 `@paper/*` 包名暂不改，以免已有的库找不到。

### M2（阅读器，已完成）
- **打开**：有 PDF 的论文双击或回车直接进阅读器，点标题看详情；详情页按钮叫"开始读"。打开时记打开时间，收件箱和待读里的论文自动变成"在读"。
- **渲染**：用 PDF.js 自带的 `PDFViewer`（按需渲染可见页、文字层、链接、查找）。PDF 通过自己的 `paper://file/<哈希>` 协议读取，支持分段请求；字体、CMap（中日韩文字）、wasm 解码器走 `paper://pdfjs/…`，不联网。渲染进程只能按哈希读库里的文件。
- **速度**：PDF.js 的 worker 启动要 2 秒左右，所以应用打开后空闲时先启动好，所有文档共用。实测（6 页生成 PDF）冷启动后第一次打开 53 ms 出第一页，再次打开 48 ms，在 300 ms 预算内。还没用大的真实论文测。
- **高亮和下划线**：工具选了就生效：用底部工具栏的高亮或下划线工具，选中文字直接标上（当前颜色）；选择文字工具只是选中，不弹任何东西。选中的文字上右键：添加批注、摘到笔记、问 AI、复制；已有的高亮上右键：添加 / 编辑批注、摘到笔记、问 AI、复制、删除（所以先高亮再问 AI 也行）。选中后按 H / U / N 仍然可以直接高亮、下划线、摘到笔记。跨页选中会按页拆成几条。点已有的高亮弹出卡片：写批注、摘到笔记、删除（可撤销）；选中一条时，底部工具栏的颜色圆点显示并修改这一条的颜色。卡片总在页面上面（每页单独一个层叠上下文，PDF 里的链接框不会盖住卡片）。跨页选中会按页拆成几条。
- **批注存储**：新表 `annotations`（数据库版本 2，旧库自动升级）。每条存 PDF 坐标的矩形（pt，原点左下，同一行合并）和"原文 + 前后各 32 字"，绑定到具体文件的哈希。重新定位用的 `findQuote` 在 core 里，有测试，桌面端现在只用矩形显示。
- **显示**：高亮按页面百分比定位，缩放时不用重画；整层和页面做正片叠底（白纸）或变亮（深色纸），文字不会被盖住。深色纸用反色 + 色相旋转，**图片也会被反色后再转回，颜色接近但不完全一样**，以后再做"图片不反色"。
- **阅读位置**：滚动停下 0.8 秒存一次，关阅读器时再存一次；下次打开回到同一位置和缩放。
- **其它**：缩略图栏（滚到才画，有批注的页带点）、批注列表（按页分组，点击跳过去）、页码可以直接输入、⌘F 查找、⌘+ / ⌘- / ⌘0 缩放、⌘[ 返回。为此换了应用菜单，去掉了默认会放大整个窗口的缩放项。
- **工具栏**（照 Figma 编辑页面）：页面区域底部居中一个工具栏，工具平铺：选择文字 V、移动页面 H ｜ 高亮 M、下划线 U，最后一个圆点是标注颜色，点开选。当前工具蓝底高亮，悬停显示名字和快捷键。按住空格临时变抓手，松开回到原来的工具；只点一下空格照常翻一屏（⇧空格往回）。任何工具下都能按住中键拖页面。高亮、下划线工具一直生效，选中文字就直接标上，按 Esc 或 V 回到选择。每次打开论文从选择文字开始。按住 Ctrl（或 ⌘）滚动滚轮、触控板双指捏合可以缩放，以鼠标位置为中心。
- **引用悬停预览**：鼠标在 [23]、Figure 2 这类内部链接上停 0.3 秒，弹出目标位置的一小块页面（约 110pt 高，字放大 1.5 倍）；双栏论文的参考文献只截目标所在的那一栏（按文字是否跨过中线判断）。下方放不下就放上方，左右不出可见区域。点击照常跳过去。
- **列表交互**（照 Zotero）：点一下论文选中并在右边详情栏显示，双击 / 回车 / 行尾"读"按钮开始读；去掉了单独的详情页和按阅读状态分的侧边栏视图。
- **外观**：整个应用统一切换浅色 / 深色（阅读器 ◐ 按钮，或菜单 显示 › 外观，可选跟随系统），用 `nativeTheme.themeSource`，存在数据目录的 `prefs.json`。
- **还没做**："图片不反色"的深色纸；同一篇有多个文件时切换文件（现在打开主文件）。

- **全屏阅读**：工具栏的全屏按钮（⌃⌘F）让窗口全屏，缩略图和右栏都收起来只留论文，Esc 退出；缩略图开关在返回按钮旁边（⌥⌘S）。深色外观下缩略图和正文一样反色。

### M3（笔记，已完成）
- **存储**：笔记就是数据目录 `notes/` 下的 `.md` 文件，文件名就是标题（和 Obsidian 一样按文件名解析 `[[链接]]`）。开头 YAML 头信息记 `id`、`paper`（关联的论文）、`created`；不认识的头信息行原样保留。别的编辑器新建的文件第一次保存时补上头信息。监听目录，外部改动自动刷新（编辑器里没有未存的修改时换成新内容）。
- **编辑器**：CodeMirror 6 上做的实时预览（Obsidian Live Preview / Typora 的交互）：标题、粗体、斜体、删除线、行内代码、链接、引用、列表圆点、待办复选框（点一下勾选）、分隔线、代码块都直接按排版显示，Markdown 符号只在光标碰到那一段（标题、引用是那一行）时淡色露出来；文件里始终是纯 Markdown。快捷键 ⌘B 粗体、⌘I 斜体、⌘E 行内代码、⌘⇧X 删除线、⌘K 链接、⌘L 待办；选中文字粘贴网址变成链接。列表、待办、引用回车自动续上；空项回车：缩进的退一级，顶层的退出并空一行（不然下一段会被当成列表或引用的延续）。
- **不需要"新建"**：切到笔记就是一个能直接写的编辑器，第一次输入才建文件（不留空笔记）；不提供固定模板，以后做用户自己配置的模板。
- **保存**：停手 0.5 秒自动保存，关掉时存最后一次。改标题 = 改文件名，别的笔记里的 `[[旧标题]]`（含别名、小标题写法）一起改掉。删除移到系统废纸篓。
- **链接**：输入 `[[` 补全笔记标题；⌘ 点击 `[[链接]]` 打开那篇（不存在就新建）。笔记底部列出"链接到这里的笔记"。
- **引用批注**：批注卡片和右键菜单里的"摘到笔记"（选中后按 N 也行），或者把右栏的批注拖进笔记，都会生成 `> 原文` + `> [第 N 页](paper://annotation/<id>)` 引用块；光标不在那一行时只显示"第 N 页"。直接点这段摘录（或"第 N 页"）就打开论文、跳到那条批注并弹出卡片；要改摘录的文字，⌥ 点击把光标放进去。
- **斜杠命令**：行首或空格后输入 `/` 弹出菜单（段落：正文、标题 1–3、无序 / 有序列表、待办、引用；插入：链接到笔记、网页链接、代码块、分隔线、今天的日期；文字：粗体、斜体、删除线、行内代码），菜单里标着对应的 Markdown 写法或快捷键。中文名、英文、拼音首字母都能筛选（`/h2`、`/bt`、`/标题`）；代码里和网址里的 `/` 不弹。
- **阅读器右栏**：分"批注 / 笔记"两个标签，宽度可以拖动（260–640）。切到"笔记"光标就在编辑器里，还没有笔记时直接写，第一次输入建一篇以论文标题命名、关联这篇论文的笔记；工具栏 + 再写一篇，一篇论文可以有多篇笔记。
- **笔记页**：侧边栏"笔记"，左边全部笔记（可筛选标题、内容、关联论文），右边编辑；没选笔记时右边就是空白草稿。
- **还没做**：用户自己配置的笔记模板；表格、公式、图片的所见即所得；高亮"飞进"笔记的动效；笔记里的图片。

### M4（AI，已完成，待用真实 Key 验收）
- **连接服务**：侧边栏"设置"里可以加好几个服务，每个填自己的 Key：Anthropic、OpenAI、Google Gemini、xAI、Mistral、Groq、OpenRouter、DeepSeek、阿里云百炼、Kimi、智谱、火山方舟、腾讯混元、百度千帆、MiniMax、硅基流动（列表在 `src/shared/aiVendors.ts`，每家只加一次），Ollama（本机，默认 `http://localhost:11434/v1`，不要 Key），以及任意多个"自定义地址"（OpenAI 兼容服务，包括本机或局域网里运行的模型，Key 可以不填，可以起名字）。打开设置时自动检查每个服务（列一下模型，不花钱），显示"已连接 · N 个模型"或连不上。Key 用 Electron `safeStorage` 加密，每个服务一个文件（`ai/keys/<服务 id>.bin`）；钥匙串不可用时拒绝保存。默认地址可以改成代理地址。请求走 Electron `net.fetch`，系统代理生效。界面上不显示价格。
- **选模型**：在对话框里选，不在设置里：AI 标签输入框左下角的模型菜单列出所有已连接服务的模型（Anthropic 用 Models API，其余用 `GET /models`，去掉向量、语音这类非对话模型），按服务分组，多了可以搜索。选了就记住，下次默认用它；第一次连上 Claude 时默认选 Opus 5.5。模型的思考块只原样发回给同一个模型，换了模型只发文字。
- **没有 Key**：AI 标签显示说明和"连接 AI 服务"按钮，其余功能完全不受影响；没连接时不会发出任何请求。
- **不自己读论文**：AI 只收到对话本身，不会把论文全文发出去。在论文里选中一段（或者已有的高亮），右键选"问 AI"，那段文字挂在 AI 输入框上，跟问题一起发出去；这是 AI 接触论文内容的唯一方式。
- **问答**：每篇论文一段对话（Enter 发送，输入法安全），流式显示。记录存在 `ai/conversations/<论文 id>.json`，按原样（含 Claude 的思考块）重放，出错或停止的那一问一答不再发给模型；"新对话"清空。每条回答可以复制或加入笔记。
- **服务端回退**：用官方地址的 Opus 5.5 / Sonnet 5.5 时默认开启 server-side fallback（主模型过载时由服务端换到备用模型）；走代理地址时不开。
- **去掉了**：划词解释卡片、论文要点、对话框里"论文文字会发给…"的提示、推荐问题。
- **还没做**：对话进数据库以便同步；多篇论文一起问。

### M5（翻译和术语，已完成，待用真实 Key 验收）
- **翻译**：在论文里选中一段（或右键已有的高亮），右键选"翻译"，旁边弹出译文卡片，流式显示，可以复制。用 AI 对话框里选的那个模型。只发这段文字，加上术语表里在这段出现的词和它们的译法，不记进对话，也不会发论文的其他部分。英文译成中文，中文译成英文；PDF 复制出来的断行和连字符先接上。选的是一个词或短语时，第一行是译法，第二行一句话说明它在论文里的意思（相当于查词卡）。没连 AI 时卡片里提示"去设置"。
- **翻译服务**（2026-11-07）：设置里的"翻译"可以选 AI 模型，或者腾讯翻译君、百度翻译、有道智云、DeepL、微软翻译的官方 API（用户自己申请 Key，除有道外每月都有免费额度：腾讯 500 万字符、百度个人认证后 100 万、DeepL 免费版 50 万、微软免费层 200 万，以官网为准）。不用 Google 网页版之类的非官方免费接口：会被当成机器人拦下，违反服务条款，随时可能失效，Google 在国内也连不上。Key 和 AI 的 Key 一样存在系统钥匙串里。填好 Key 就自动换成这家，并试译一个词检查。机器翻译不认术语表，卡片顶上照样显示定好的译法；有道查单词时第二行是释义。
- **macOS 系统翻译**（2026-11-08）：默认的翻译服务，免费、不用注册、在本机翻，文字不离开电脑。用 macOS 26 的 Translation 框架，通过随 App 带的小助手 `native/translate/main.swift` 调用（`scripts/build-native.sh` 在 dev/build 前编成通用二进制，打包放到 `Resources/bin/flax-translate`；要 Xcode 26，没有就跳过，CI 也要 Xcode 26）。英语、中文（简体）两种翻译语言要用户在 系统设置 › 通用 › 语言与地区 › 翻译语言 里下载一次，没窗口的小助手下载不了，所以设置里带着去，切回 Flax 时自动再查。用户没选过时：系统翻译能用就用它，否则有 AI 用 AI，都没有就指向系统翻译引导下载。系统翻译不认术语表。
- **批注列表改版**（2026-11-08，参考 Zotero、Readwise、Apple Books）：一条一行，不再每条一张卡片，悬停淡底、选中白底；原文最多三行；评论无衬线、带图标、淡底，和原文分开。在列表里点一条就在这一行展开：改评论（失焦或 ⌘↩ 保存，Esc 收起）、换颜色、摘到笔记、复制原文、删除，不再弹页面上的卡片；在页面上点高亮，列表滚到那一条并标出来。超过 8 条时顶上有筛选：按颜色、只看有评论的。去掉了常驻的"把批注拖进笔记"提示，拖动照样能用。右键列表里的一条：添加/编辑评论、摘到笔记、复制原文、删除（删除后可以撤销），菜单开着时那一行有描边。抓手工具下点一下（没拖）也能打开高亮的批注卡片，点空白处收起（以前抓手下点哪里都不处理，卡片关不掉）。
- **只写评论不涂色**（2026-11-08，参考 Acrobat 的"给文字加评论"）：选中文字右键"添加批注"不再先涂成高亮，存成 `type: note`：页面上只有一条灰色虚线和页边的评论标记，列表里左边是虚线竖条，不算进颜色筛选。评论框和列表展开行里都有颜色，选一个就变成那个颜色的高亮（评论保留）。评论框关掉时还是空的就当没加过，悄悄删掉（重新读一次再判断，刚写的评论可能还在保存）。用高亮、下划线工具标的照旧。
- **页边评论标记**：有评论的高亮，在离它近的那一侧页边、和第一行对齐的地方放一个小标记（带高亮颜色的竖条和评论图标），代替原来高亮左上角的小圆点。悬停显示评论，点一下打开这条批注的卡片（再点收起），列表也跟着选中。标记单独一层放在文字层上面，只有标记本身能点，不挡选字。
- **双击翻译**：选择工具下双击一个词，翻译能用时直接弹出译文卡片；选区留着，右键照样能批注。翻译没设好时双击只是选中。抓手工具（或按住空格）下也能双击翻译：按下去只拖页面、不选字，但双击不会拖动，所以用 `caretPositionFromPoint` 找到鼠标下的字（临时打开文字层的鼠标事件），按 `Intl.Segmenter` 切出那个词选中再翻；再按下去拖页面时清掉选区。Acrobat 的做法是抓手停在文字上就变成选字光标，论文满页都是字，那样抓手就拖不动了，所以没学。
- **术语表**：短的选区翻译完可以点"加入术语表"（原文和译法都能改了再存）；已经在表里的词，卡片顶上显示定好的译法，按钮变成"改译法"。之后翻译时同一个词都按这个译法，全文一致。匹配按整词（`head` 不匹配 `headline`），复数、连字符、跨行都算。
- **术语页**：侧边栏"术语"。表格列出原文、译法、备注和来自哪篇论文（点一下打开）；直接点格子就能改，回车保存、Esc 放弃；可以筛选、手动添加；删除可以撤销。存在 SQLite 的 `terms` 表（schema 版本 3），和论文、批注一样带 `id / updatedAt / deviceId`，软删除。
- **不做**：整页"原文 / 对照 / 译文"模式（2026-11-07 用户决定：右键翻译够用，阅读器保持简单）。
- **还没做**：术语表导入导出。

- **复制引用**：文献库里右键一篇论文，"复制引用"下有 APA、GB/T 7714、BibTeX 三种格式，复制到剪贴板。格式化在 `packages/core/src/cite.ts`，纯函数，有测试（中文作者、arXiv、缺字段）。
- **导出**：右键一篇论文"导出 BibTeX… / RIS…"；菜单栏 文件 › 导出全部为 BibTeX / RIS。引用键是"第一作者姓 + 年份 + 标题第一个实词"，重名加 a、b、c。
- **从 Zotero 迁移**：空文献库上的"从 Zotero 迁移"按钮，或菜单栏 文件 › 从 Zotero 或 BibTeX 导入…。在 Zotero 里用"导出文献库"，格式选 BibTeX、勾选"导出文件"，选中导出的 .bib 就行：标题、作者、年份、期刊、DOI、arXiv、摘要、关键词（变成标签）都带过来，`file` 字段里的 PDF 会复制进库（Zotero 的 `描述:路径:类型` 写法和转义都支持）。已经在库里的（同一文件、DOI、arXiv 或标题）不重复添加，没有 PDF 的会补上。做完弹出"新加 N 篇，M 篇库里已有，K 个 PDF 没找到"。解析器支持 `@string`、`#` 拼接、嵌套大括号和常见 LaTeX 重音，一条坏掉的记录不影响后面的。
- **菜单栏**：照 Mac 习惯补全：Flax › 设置…（⌘,）；文件 › 导入 PDF…（⌘O）、从 Zotero 或 BibTeX 导入…、新建笔记（⌘N）、导出；帮助 › 键盘快捷键（⌘/），弹出一张列出所有快捷键的表。菜单项全部是中文。
- **不做**：迁移 Zotero 里的批注和笔记（2026-11-07 用户决定：BibTeX 带过来的信息、标签和 PDF 够用）。
- **还没做**：用一个真实 Zotero 库验收（需要用户的数据）；Markdown 导出；按文件名规则导出 PDF；迁移报告页（现在只有一条汇总提示）。

- **找不到 PDF**：资料文件夹里的 PDF 被移走或删掉时，阅读器说清楚是哪种情况，批注和笔记都还在，按钮"重新选择 PDF…"选回文件后阅读器重新加载；选回同一个文件，批注照原样显示。选的不是 PDF、或者属于库里另一篇，会提示。没有打开文档时不显示底部工具栏。

- **浮层不出界**：翻译卡片、批注卡片靠近页面左右边缘时往里收。
- **深色模式**：文献库、详情、阅读器、笔记、术语、设置、快捷键表都看过一遍。
- **版本号**：0.1.1。
- **出错时让人知道**：笔记没能写进文件（没有权限、磁盘满、文件夹不见了）时，底部显示"没能保存：原因 · 重试"，内容留在编辑器里，下次输入或点重试会再存，存上了恢复"已保存"。其他操作在主进程出错又没被单独处理的，统一弹提示"没能完成：原因"（取消类的不提示）。BibTeX 文件里一条文献都没有时，说清楚可能选错了文件。
