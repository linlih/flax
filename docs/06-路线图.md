# 06 路线图

> 状态：草案 v0.2（2026-11-05，按原型 review 收紧了阶段 1 的范围）。每个阶段只把少数几件事做到极致；没有达到退出标准，就不进入下一阶段。

## 阶段 0：验证与设计（约 4–6 周）

**目标**：确认差异点成立，定下数据契约和设计规范。

- [ ] 完成 [01-定位与差异化](01-定位与差异化.md) 里的待核实清单（竞品实测、用户访谈）
- [ ] 设计 token 和组件规范
- [x] 高保真可交互原型：文献库首页、阅读器、阅读加笔记分栏、iPad 用笔圈选问 AI
- [x] 补齐 MVP 必需界面的原型：首次打开、AI 与翻译设置、Zotero 迁移、出错和空状态
- [x] 补齐 P1 界面原型：笔记页、论文详情和标签、导出引用、桌面查词
- [ ] 用原型做 5 人以上用户测试
- [x] 设计深色模式 token（文献库、阅读器、笔记三个界面已出深色原型）
- [ ] 定稿批注格式（[04-数据模型](04-数据模型.md)），并验证同一条批注在 PDF.js 和 PDFKit 上位置一致
- [ ] 完成 CRDT 选型对比（Automerge 还是 Yjs）
- [ ] 搭好 monorepo、CI、许可证扫描

**退出标准**：至少 5 位目标用户试用原型后，认为"比现在用的工具好"；批注跨渲染器验证通过。

## 阶段 1：桌面版 MVP（约 3 个月）

**目标**：桌面上"读一篇论文"的体验超过 Zotero 和小绿鲸。

- [ ] 首次打开：空文献库引导拖入第一篇 PDF；AI 可以稍后设置，不设置也能读和批注
- [ ] 文献库：拖入 PDF、自动识别元数据、去重、重命名；文件夹 + 标签（智能筛选放到之后）
- [ ] 阅读器：**只支持 PDF**（见 [07-阅读格式与手写策略](07-阅读格式与手写策略.md)），PDF.js 渲染，高亮、下划线、批注，引用悬停预览
- [ ] 笔记：Markdown、双链、高亮拖成引用块
- [ ] 翻译：划词翻译和查词卡；按段落的全文翻译（原文 / 对照 / 译文）；简单术语表（自动提取、确认、锁定译法）。保留排版的翻译版 PDF（BabelDOC）放到之后
- [ ] AI：用户自带 API Key 或本地模型（Key 存系统钥匙串）；划词解释；单篇问答（带原文定位）
- [ ] 论文要点：每篇论文自动生成导读（一句话 + 建议怎么读）和结构化要点，用户修正（结构化部分顺手积累，不作为卖点）
- [ ] 本地同步基础：数据通过 CRDT 存储，文件按哈希存储，可以同步到用户选择的文件夹（为下一阶段准备）
- [ ] 导入导出：BibTeX、RIS、Markdown；Zotero 文献库迁移（条目、附件、分类、标签、高亮、笔记，带导入报告）
- [ ] 所有出错和空状态：没有 API Key、离线、AI 中断、扫描版 PDF、元数据找不到、重复导入
- [ ] 浅色和深色模式
- [ ] 达到 [05-体验原则](05-体验原则.md) 里的桌面性能预算

**退出标准**：50 位种子用户中，30% 以上持续使用 4 周以上。

## 阶段 2：iPad 版 + 同步（约 3 个月）

**目标**：桌面和 iPad 无缝衔接的精读，这是核心差异点 D1 和 D2。

- [ ] React Native 应用：文献库、笔记、AI 对话
- [ ] 原生阅读器模块：PDFKit + PencilKit；笔迹转换为开放格式
- [ ] 用笔圈选 → 问 AI、翻译、高亮、摘到笔记
- [ ] 笔势：划过文字自动吸附成高亮；圈选问 AI；套索拖进笔记
- [ ] 所有文本框支持 Scribble 手写转文字（批注、标签、笔记、AI 提问）
- [ ] 多设备同步：iCloud Drive、WebDAV、S3、R2；阅读位置同步
- [ ] 桌面端渲染 iPad 上的笔迹
- [ ] 开源发布：AGPL、CLA、商标、`THIRD_PARTY_NOTICES`

**退出标准**：同步可靠（零数据丢失，冲突自动解决）；iPad 手写体验在用户测试中接近 GoodNotes。

## 阶段 3：知识层 + 手机版（约 3 个月）

**目标**：从"读这一篇"走向"读过的都能复用"。

- [ ] 全库问答（RAG，回答带原文定位）
- [ ] 多篇论文对比表（基于论文要点的结构化字段）
- [ ] 术语概念页：术语出现在哪些论文里、全库相关批注、笔记双链（阶段 1 只做简单术语表）
- [ ] 带文献库上下文的阅读提示（"这个方法你在 A 论文里读过"）
- [ ] 相关工作草稿生成（带引用）
- [ ] arXiv 订阅和每日推荐收件箱，AI 三句话帮你判断要不要读
- [ ] HTML 阅读模式：优先使用 arXiv 官方 HTML，没有时从 PDF 解析生成；显示有问题时一键切回 PDF
- [ ] 笔势扩展到 HTML 模式；PDF 上的笔迹在 HTML 中显示为段落标记
- [ ] 手机版：默认使用 HTML 阅读模式；收件箱、快速判断、收藏入库、回顾高亮和卡片、AI 问答
- [ ] 浏览器插件：一键保存论文

## 阶段 4：扩展（之后）

- [ ] HTML 模式下的锚定手写便签；手写识别做索引（让笔迹可以被搜索）
- [ ] Android 平板和手机（PDFium + 手写笔）
- [ ] Word 和 Google Docs 引用插件；CSL 引用格式
- [ ] 可选的官方托管同步服务和 AI 额度（可持续收入）
- [ ] Linux 桌面版完善
- [ ] 插件系统

## 刻意不做（至少在阶段 3 之前）

- 多人协作、共享文献库
- 社区和社交功能
- 公共论文搜索引擎（使用现有的 API 即可）
- 人文社科长篇写作的复杂引用排版
