# Flax 项目方案

<img src="../brand/png/flax-icon-128.png" width="64" height="64" alt="Flax 图标：折纸 F">

产品名 **Flax**（亚麻，早期造纸的原料）。图标和品牌资源见 [brand/](../brand/README.md)。

开源、本地优先的论文阅读与知识工具：**桌面管理 + iPad 原生精读 + AI**，体验做到极致，数据永远属于你。

## 关键决策记录

| 日期 | 决策 | 理由 |
|---|---|---|
| 2026-11-03 | 不依赖 Zotero（不运行、不作为后端） | 产品独立性；避免受制于他人的架构 |
| 2026-11-03 | 采用 AGPL-3.0 + CLA + 商标 | 防止闭源抄袭；可以合法使用 AGPL 组件；保留以后做商业化的可能 |
| 2026-11-03 | 护城河 = UI 和交互打磨 + 迭代速度 | 功能容易被抄，知识沉淀需要长期积累 |
| 2026-11-03 | 桌面用 Electron | 跨平台渲染一致，适合精细打磨；PDF.js 表现最好 |
| 2026-11-03 | 移动端用 React Native，iPad 阅读器用原生 Swift（PDFKit + PencilKit） | iPad Pencil 批注是必须项；可以和桌面共享 TypeScript 核心 |
| 2026-11-03 | 批注使用开放格式（PDF 坐标 + 原文定位；笔迹是点序列） | 跨渲染器、跨平台一致；不锁定数据 |
| 2026-11-04 | 第一版只支持 PDF 阅读；HTML 阅读模式在第三阶段和手机版一起做 | PDF 排版最美观、覆盖所有论文、最适合手写；数据模型提前为 HTML 预留 |
| 2026-11-04 | HTML 模式不在文字上方自由手写，改用手写转文字、笔势转批注、锚定手写便签 | 重排会让坐标式笔迹错位 |
| 2026-11-04 | 视觉方向改为「Apple 原生感」（v0.2「墨与荧光笔」被否决） | v0.2 颜色杂乱、深色侧边栏突兀；按 Apple HIG 让界面像系统自带应用一样安静，颜色只留给强调色和论文高亮 |
| 2026-11-06 | 产品名定为 Flax | 单音节、只有一种读法的真实英文词；亚麻是早期造纸原料，和“纸、论文”有关；同品类（论文/PDF/笔记/AI 阅读）没有重名。已知同名：Google 的 JAX 神经网络库 Flax（不同类）；USPTO 有一件待审的 FLAX 申请（Erply Software，零售收银软件，第 9/35/42 类） |
| 2026-11-06 | 图标定为「折纸 F · 全蓝冷调」 | 一条纸带折成 F，正反两面表现“纸”；小尺寸可辨认。源文件和各平台尺寸在 [brand/](../brand/README.md) |
| 2026-11-09 | 同步不用 Automerge 或 Yjs，改成按记录、按字段合并的变更日志；笔记正文用版本向量 + 按行三方合并 | 数据本来就是一条条记录；笔记是 Obsidian 也能改的 .md 文件，CRDT 文本用不上。见 [11-移动端与同步规划](11-移动端与同步规划.md) |
| 2026-11-09 | 先做同步，再做移动端；手机先于 iPad；第一个后端是坚果云（WebDAV）；端到端加密默认开启 | 没有同步的移动端没有意义；国内用户首选坚果云；存储在第三方手里 |
| 2026-11-09 | iPad 版以 iPad Pro 11 英寸（M5）为主要适配对象，横屏为主；顺序仍是手机先于 iPad | 用户自己的设备 |
| 2026-11-09 | 资料文件夹、包名、协议改成 Flax（`Flax/Library`、`@flax/*`、`flax://`） | 有同步之后再改，云端也要跟着迁移；旧的资料第一次启动时自动搬过来 |
| 2026-11-10 | 手机上别的设备加的 PDF 打开时才下载；Android 阅读器只搬桌面的高亮绘制，操作面板用 RN 写 | 手机空间小；桌面阅读器的工具栏和菜单在手机上都要换，整个搬过来改动更多。见 [11-移动端与同步规划](11-移动端与同步规划.md) 第 12 节 |
| 2026-11-11 | Android 不做手写；检查更新只给浏览器下载链接，不在应用里装；发布签名的 keystore 放在 apps/mobile/signing/，不进 git | 桌面和批注数据都没有手写，单独在手机上加一种桌面看不了的批注不合适；自己装 APK 要额外权限，交给系统更稳；keystore 丢了以后就发不了更新。见 [11-移动端与同步规划](11-移动端与同步规划.md) 第 13 节 |
