3.2 Attention

An attention function takes a query and a set of key–value pairs and produces an output. The output is a weighted sum of the values, where each weight reflects how well the query matches the corresponding key.

We call our variant Scaled Dot-Product Attention. The dot products of the query with all keys are divided by the square root of the key dimension before a softmax is applied, which keeps the gradients stable when the dimension is large.

Attention(Q, K, V) = softmax(QKᵀ / √dk) V (1)

The two most widely used alternatives are additive attention and plain dot-product attention. Dot-product attention is faster and more memory-efficient in practice because it can be computed with highly optimized matrix multiplication.

For small key dimensions the two mechanisms perform similarly. For larger dimensions, additive attention does better unless the dot products are scaled, because their magnitude grows with dk and pushes the softmax into regions where its gradients are tiny.

3.2.2 Multi-Head Attention

Rather than computing a single attention function over full-width keys, values and queries, we found it useful to project them several times with different learned projections and attend to each projection in parallel. The outputs are concatenated and projected once more.
