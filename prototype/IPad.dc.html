3.2.2 Multi-Head Attention多头注意力

Instead of one attention function over full-width keys, values and 查询, we project them h times with different learned projections投影, and run attention on each projection in parallel.

我们不在全宽的键、值和查询向量上只做一次注意力，而是用 h 组不同的、可学习的投影把它们各投影一次，再在每份投影上并行做注意力。

In this work we use h = 8 parallel heads. For each head the key and value dimension维度 is dmodel / h = 64, so the total cost stays close to single-head attention at full width.

本文使用 h = 8 个并行的头。每个头的键和值维度是 dmodel / h = 64，所以总计算量和全宽的单头注意力差不多。
